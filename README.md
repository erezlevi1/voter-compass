# מצפן הבוחר — Voter Compass Israel

מצפן בחירות עצמאי, נייטרלי וחינמי לקראת הבחירות לכנסת ה‑26 (27 באוקטובר 2026).

**🔗 [voter-compass.vercel.app](https://voter-compass.vercel.app)**

איננו מסונפים לאף מפלגה ואיננו ממומנים על ידי גורם פוליטי. הכלי אינו אומר למי להצביע — הוא מציג מידע, מסביר את המחלוקות, ומראה היכן עמדותיך ממוקמות.

## למה זה שונה

כל כלי בחירות מצהיר שהוא אובייקטיבי. במקום להצהיר, האתר **בודק את עצמו** בכל ביקור:

- **מבדק תקינות** — שלכל טענה יש מקור, שהעמדות שלמות, שסכומי התקציב מסתדרים, ושהנתונים לא התיישנו. כישלון מוצג באדום, לא מוסתר.
- **סריקת שפה טעונה** — לקסיקון מונחים נסרק בטקסט שאמור להיות ניטרלי (ולא ב"טיעון של כל צד", שם המטרה היא דווקא לשכנע).
- **הצלבה בין מאגרים** — מתריע על סתירות ועל ערבוב תקופות (מנדטי 2022 לצד סקר 2026).
- **בקרת מפה פוליטית** — מזהה מיזוגים ורשימות שנעלמו, ומסדיר את האפליקציה בהתאם.
- **הכל פתוח** — [מאגר הנתונים](https://voter-compass.vercel.app/#/database) זמין להורדה כ‑JSON עם המקורות. אפשר להצליב ולתקן אותנו.

## פרטיות

אין הרשמה, אין חשבונות, אין עוגיות מעקב ואין אנליטיקס. **השאלון רץ כולו בדפדפן** — התשובות אינן נשלחות לשום שרת ואינן נשמרות. [מדיניות הפרטיות](https://voter-compass.vercel.app/#/privacy).

## מבנה

```
index.html          האפליקציה (SPA עם hash routing, ללא תלויות)
data/*.json         כל הנתונים — פתוחים לעריכה ולביקורת
api/
  news.js           כותרות מפידי RSS ישראליים, בצד השרת
  live-polls.js     סקרים מוויקיפדיה → שער אימות
  page.js           עמודי תוכן שנבנים בזמן הבקשה (28 כתובות /guide/)
  sitemap.js        מפת אתר דינמית עם lastmod מדויק
  _shared.js        הגנות: נרמול כתובות, זיכרון עם תפוגה, מגבלת קצב
.github/            שומר יומי שמתריע על שינויים במפה הפוליטית
```

**פריסה:** Vercel. ללא build step, ללא תלויות npm.
